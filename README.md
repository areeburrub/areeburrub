# Hey, I'm Areeb 👋

Backend & applied AI engineer. I build production systems, LLM pipelines, scrapers at scale, and the infra underneath them.

Currently a **Founding Engineer @ [SocialSonar](https://socialsonar.app)**, where I:
- Architected a supervisor/routing pattern for our LLM pipeline that cut inference costs ~40%
- Migrated our infra from AWS ECS to self-managed Kubernetes (Hetzner/K3s), cutting infra spend from $400/mo to $80/mo
- Built LangGraph pipelines processing 100k+ mentions/week across 8+ social platforms and thousands of news sites

I mostly work in **TypeScript/Node (NestJS, Next.js)** and **Python**, with Postgres, Redis, Docker/K8s, and LangChain/LangGraph day-to-day.

🧠 I write about what breaks in production and what I learn fixing it → [areeburrub.dev/blogs](https://areeburrub.dev/blogs)

🛠️ Currently building [Drized](https://github.com/areeburrub/drized) an AI virtual try-on tool processing thousands of requests/month.
